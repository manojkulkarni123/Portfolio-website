This is the first post on the blog. Posts are plain MDX files in `content/blog`, committed to Git and deployed on Vercel.

## Writing a post

Create `content/blog/my-post.mdx` with front matter:

```yaml
title: "My post"
date: "2026-12-01"
summary: "One line shown in the list."
tags: ["kubernetes"]
```

Code blocks are highlighted at build time:

```python
def greet(name: str) -> str:
    return f"hello, {name}"
```
